## Описание проекта
Стилизация страницы «О себе» с демонстрацией способов подключения CSS, работы с селекторами, типографикой, пастельной палитрой цветов, отступами, позиционированием и псевдоклассами.

## Реализованные требования

### 1. Способы подключения стилей
* **Внешний файл:** основной файл `style.css` подключен через тег `<link>`.
* **Внутренний блок:** тег `<style>` в блоке `<head>` содержит правила для поля `textarea` (увеличенная высота, внутренняя тень `box-shadow: inset`, моноширинный шрифт).
* **Inline-стиль:** тегу `<aside>` задано свойство `style="background-color: rgba(255, 255, 255, 0.7);"` для полупрозрачного фона.

### 2. CSS-переменные (`:root`)
* Основная гамма: фиолетовые оттенки (`--primary-color`, `--primary-dark`, `--active-border`).
* Акцентный цвет: белый (`--accent-color`).
* Переменные для типографики: основной шрифт (`--font-main`) и моноширинный (`--font-mono`).

### 3. Типы позиционирования
* `position: static` — явно указан для шапки страницы (`header`).
* `position: relative` — контейнер карточки проекта (`.project-card`).
* `position: absolute` — декоративный бейдж «★ Избранное» (`.favorite-badge`) в верхнем правом углу карточки.

### 4. Интерактивные состояния элементов
* `:hover` — плавный подъем карточек проектов, подчеркивание навигационных ссылок, изменение оттенка кнопки.
* `:active` — визуальный отклик нажатия (масштабирование кнопки `scale(0.97)`).
* `:focus` — для кнопки отправки формы реализована белая рамка толщиной 3px (`outline: 3px solid #ffffff`), для текстовых полей — цветная подсветка контура.
* `:visited` — отдельный фиолетово-пурпурный оттенок для посещенных навигационных ссылок.

### 5. Особенности Варианта 4
* Реализован класс `.active-section` с яркой рамкой и мягкой тенью, динамически подсвечивающий текущую секцию при скролле (Intersection Observer API).
* Контрастность текста на светлом лавандовом и белом фоне превышает 13:1 (при норме стандарта WCAG не менее 4.5:1).
